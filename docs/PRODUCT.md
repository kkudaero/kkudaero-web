# 꾸대로(kkudaero) 제품 개요

에이전트와 개발자가 작업 전에 읽는 제품 요약입니다. 이 저장소는 공개 예정이라 사업 계획 세부는 담지 않습니다.

## 한 줄 정의

일본 구매대행을 처음 시작하는 1인 사업자가 첫 주문부터 통관까지 혼자 헤매지 않게 해주는 웹 도구.

## 원칙

- 공식 자료 기반 체크리스트, 계산기, 통관 알림, 대응 매뉴얼을 제공하는 **도구**다.
- 관부가세·마진·목록통관 판정은 **서버가 계산**하고, 화면에는 항상 **"예상"** 값으로 보여 준다.
- 체크리스트·매뉴얼·안내 문구는 **서버 API로 받아 온다.**
- 통관 신고를 대신하지 않는다. 필요하면 배대지나 관세사에게 안내한다.
- 웹이 본체다. 웹만으로 모든 기능을 쓸 수 있어야 한다.

## 1단계 기능

| 기능 | 폴더 이름 | 내용 |
|---|---|---|
| 시작 체크리스트 | `checklist` | 사업자등록부터 배대지 가입까지 단계별 진행 |
| 관부가세·마진 계산기 | `calculator` | 150달러 목록통관 판정, 합산과세 경고, 예상 마진 |
| 통관 조회·알림 | `customs` | 운송장번호로 통관 진행 상태 확인, 상태가 바뀌면 알림 |
| 대응 매뉴얼 | `manual` | 통관 보류, 통관부호 오류·만료, 품절, 배송 사고 대응과 고객 안내 문구 |
| 주문 추적 | `orders` | 셀러가 직접 입력하는 주문 → 발주 → 배대지 → 송장 추적 보드 |

## 함께 쓰는 저장소

- `kkudaero-server`: API 서버. OpenAPI 명세(`/v3/api-docs`)로 이 저장소의 API 타입을 생성한다.
- `kkudaero-ios`: 알림 확인·송장 입력용 보조 앱.
